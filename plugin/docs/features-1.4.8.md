# 1.4.8 本地更新

好友回复修复及运行状态已同步插件和独立软件。本次仅更新本地，尚未公开发布。

- 在业务设置的“视频观看”顶部补回“开始自主观看”和“暂停观看”。按钮与允许自动观看开关同步，保留当天已用时间和请求数；不在时段内会等待。
- 增加常驻状态栏：准备中、在线等待消息、看视频中、挑选视频、回复中、需要处理。只有模型、真实回复进程心跳和所选会话检查都就绪才显示在线。
- 解除联系人暂停会协调等待原服务停止、执行本人核对并按总开关恢复，避免与默认自动回复冲突。
- 修复无待答的普通停止被记成暂停、名单维护吞掉已确认未发送消息的问题。维护恢复需要原始新到达资格、同一强身份、消息指纹及未发送证据；五分钟过期、用户已回或发送结果不明时保留人工待答。
- 读取当前会话列表时遍历虚拟滚动列表；部分列表不再覆盖原许可名单。界面分别显示已许可、关注核对状态和个人/群/未知会话数量。范围仅限当前抖音网页版消息列表。
- 修复昵称草稿误保存、原生状态刷新并发，以及人格冲突恢复时读取旧版本的问题。
- 原生自动回复启动时立即绑定共用用量账本，不再等待打开设置页。平台没有返回的Token仍标为未知。
