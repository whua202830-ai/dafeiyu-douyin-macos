# 1.4.5-beta.1 本地测试版

以下保留 2026-10-24 测试时的功能快照，当时 GitHub 正式版为 1.4.4。当前使用说明见 [1.4.5](features-1.4.5.md)，公开状态见[发布记录](publication.md)。

- 个人和群聊按平台稳定标识核对，昵称与头像用于展示。只保留用户所选会话，群聊只响应 @ 或设定昵称。
- 私信按共用手编人格接话，不默认自称自动回复助手；只使用当前会话的显示名与类型，不提供其他联系人或 QQ 历史。
- 设置自动保存。观看使用允许时段、每日时长及请求额度，高级选项可折叠；保留开始自主观看与暂停入口。
- 原生插件与软件共用真实用量和运行状态，读取失败不沿用旧在线状态。
- 修复观看计时 1 毫秒误差、重复分享误停以及换片过渡帧判断。已处理的分享只跳过，不重发、不重复计数。
- 换片前核对唯一稳定作品 ID，点击后只回读确认，不盲目连点；作品已变化时丢弃旧决策并重新观察。

测试版检查更新时会明确区分测试版与 GitHub 正式版，未来可升级到正式 1.4.5。
