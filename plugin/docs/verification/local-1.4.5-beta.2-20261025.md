# 1.4.5-beta.2 本地验证记录

日期：2026-10-25。软件、DSH 插件和本地合并启动器已更新为 1.4.5-beta.2。本轮没有推送、发布 npm 包或创建 GitHub Release。

## 本轮六项修复

| 问题 | 修复与验证 |
| --- | --- |
| 分享按昵称、头像匹配，有认错收件人的风险 | 许可身份绑定平台稳定标识，再核对该行按钮的目标标识。隔离 Edge 中实际触发 pointerdown 后同 DOM 从 A 改为 B，发送处理器未执行，返回 FORWARD_INPUT_IDENTITY_CHANGED；稳定 A 对照只发生一次可信发送。 |
| 当前网页分享一直未发送，且缺少具体原因 | 适配当前分享入口与面板。真实专用浏览器已向原许可好友发送一次当前观察作品，回读到对应作品的新发出官方卡片及平台消息 ID。新失败保存阶段、错误码和去敏说明，两版可查看；旧记录缺少的细节不补造。 |
| 转发器残留最多 50 人限制 | 移除人数上限，超过 50 个稳定许可会话的回归通过；重复、无身份或类型冲突的名单仍会拒绝。 |
| 正常分享被误报为需要处理 | 存活发送锁必须与当前 operationId 和进程精确对应，才显示分享中。真实分享取得 408 个活动样本，没有误报暂停；旧预留、死亡锁和 uncertain 仍要求核对。 |
| 换片等待期间 A 变 B，旧决策可能误跳 B | 等待中持续核对作品、几何、命中、预算和取消；可信输入到达时同步核对原作品。隔离 Edge 覆盖等待中、最终输入间隙和超时后的变化，不产生过期换片。 |
| 无文字验证码没有阻止视频操作 | 视频状态补齐可见验证码容器判断；观察、换片和最终输入遇验证层即停止。真实 Edge 合成遮罩回归通过。 |

## 本地运行

插件原生接口和软件后台均回读为 1.4.5-beta.2，39 个领域源文件与打包内容一致。两版共用同一存活回复工作进程和用量账本，原两位个人许可会话的 ID、类型、授权时间和稳定身份绑定均保留。原观看与互动设置、前一日历史用量仍在，没有清零额度、删除旧收据或重发旧作品。

持续观看验收为 200.205 秒、11 次状态采样，始终在线，没有 failed、needs_user 或错误。该期间实际累计观看约 199.499 秒，观看模型请求由 3 增至 20。检查结束时自主观看和许可好友回复服务仍运行，公开评论保持原来的关闭状态。

真实分享通过 AutonomousShare 的正式许可、去重、账本与 VideoForwarder 事务完成，没有构造替代授权。结果为 confirmed、native-card，且取得新平台消息 ID。测试只使用原许可名单中的一位，没有扩大联系人范围。
