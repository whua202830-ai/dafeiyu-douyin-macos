# 1.4.5-beta.1 本地验证记录

日期：2026-10-24。软件、插件和本地合并启动器已统一显示 1.4.5-beta.1；GitHub 正式发布仍为 v1.4.4。本轮未发布、推送或修改远端仓库。

## 修复与现场证据

原两位个人许可会话已按平台稳定标识核对，原 ID、类型和授权时间保留。昵称和头像不再决定授权。当前没有真实群聊，群触发与发送边界只做合成验证。

共用人格文件存在且已注入回复。固定“自动回复助手”定位被移除，当前人格决定角色表达；仅附加当前会话显示名和类型。真实新消息在聊天模块未变的内部构建上约 3.953 秒取得平台发出记录。测试版与该次实测的聊天模块一致，口吻是否满意仍由本人判断。

修复了三类提前结束：旧计时器多取时间造成 2001 毫秒租约并误报损坏；重复分享被当成整段观看错误；换片前 ID 暂缺仍输入、读回等待过短及模型决策过期。保留每日记录、原收据和原许可，不清零预算，不自动重发。

最终真实专用浏览器观察约 200 秒，完成 11 次状态采样，未出现 failed 或 needs_user；该期间实际累计观看约 186 秒，请求数由 45 增至 55。仅处理原许可范围，没有发布公开评论。

## 检查结果

- 较早完整回归：712 项通过、7 项原有跳过。
- 人格、聊天和计时相关回归：235 项通过、2 项原有跳过。
- 重复分享、观看行为和 HTTP：63 项通过。
- 最终换片核心：42 项通过；观看衔接：46 项通过。
- 测试版版本比较和更新器：9 项通过。
- 安装包源文件摘要、图标、15 个接口、设置、诊断和正常退出检查通过；正常退出后后台端口释放。
- 插件干净安装另行核对，没有启动真实浏览器或调用模型。

这些测试有重叠，不将条数相加，也不将合成页面测试视为真实群聊或长期运行成功。

## 保留的限制

最小化聊天窗口曾有一次打开超时，约 25 秒后自动恢复。旧日志未保留点击细节，尚未确定是低刷新率还是层叠动画所致，不将它列为已完全解决。分享正在执行时，状态栏可能短暂显示“需要处理”，随后自行恢复；这项提示还需细分。当前真实群聊和长时间无人值守运行尚未验收。

此前 1.4.6 至 1.4.12 仅为本机内部构建标签。测试原始记录保留原标签供追溯，当前统一的产品测试版本是 1.4.5-beta.1。
