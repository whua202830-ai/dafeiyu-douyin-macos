# 1.4.11 本地验证记录

日期：2026-10-24。范围是本机 DSH 插件、独立软件和专用抖音浏览器；尚未公开发布。

## 已核实的问题与修复

- 会话主身份改用已渲染的平台稳定标识，昵称和头像用于展示。原两位许可会话的列表和聊天标题身份已在真实页面交叉核对。旧授权只按原 ID 与类型升级。
- 私信确实读取共用手编人格。先前固定的“自动回复助手”角色压过人格，现已调整为人格决定日常角色表达，只在被问及 AI 身份时诚实说明。已给回复模型当前会话的显示名和类型，不给其他人的资料。
- 默认私信回复实际得到平台发出记录。1.4.10 新消息从收到到发出回执为 3.953 秒；这一版与 1.4.11 的聊天模块相同。口吻是否满意仍由本人判断，不以测试代替体验。
- 实测计时账本曾出现 2001 毫秒的租约：旧写入连续三次取时，造成 1 毫秒差异。修复为单次取时；窄范围旧记录只缩短内存租约，不清零已记时长和请求数。本机修复前备份保留。
- 持续观看发现已处理过的分享误停整个观看，已改为核对后的明确跳过。原收据与去重记录保留，未确认结果仍需处理。
- 自动回复与分享共用聊天标签的操作改为公平排队；不同入口认领各自标签，并核对归属。

## 验证范围

1.4.9 全量：712 项通过、7 项原有跳过；1.4.10 相关回归：235 项通过、2 项原有跳过。1.4.11 分享、观看及 HTTP 定向 41 项通过。真实模型候选只在本地评审，没有作为测试消息发给好友。

真实验证只覆盖原许可的两位个人会话。当前没有被许可的真实群聊，群触发及外发只做合成页面测试。没有发布公开评论，也没有读取名单外私信正文。最小化窗口曾有一次会话打开超时，约 25 秒后自动恢复；因旧日志没有保留点击失败细节，尚不能确定是低刷新率还是层叠动画导致，不把它列为已完全解决。

安装包启动、界面、源码摘要和干净安装另有本机验收记录。持续运行结果完成后补充在本记录末尾。
