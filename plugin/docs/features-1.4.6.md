# 1.4.6 本地更新

插件与软件使用相同设置规则。当前版本尚未公开发布。

- 设置自动生效，取消保存按钮。开关立即提交，合法数字与时段等待约600毫秒，Key与人格正文离开输入框后提交。保存失败保留草稿。
- 好友互动共用一个开关，默认开启。只处理已选好友和群聊；群聊仅在被@或叫到设定昵称时回复。取消人数、回复次数、分享次数上限，移除续火花。已有发送核对和去重记录保留。
- 允许观看后在设置时段内自动运行，无需手动开始新轮次。每日观看分钟与模型请求上限在折叠的高级选项中修改，也可选不限。
- 插件和软件共用上海日期的实际播放时间和请求账本，修改规则或重启不会清零。平台返回一次响应就记录一次Token；进行中的请求显示等待平台返回用量。

显示的Token只涵盖本助手收到的平台响应；其他DSH会话和云端音频不包含在内。实机与隔离测试结果以本次验收记录为准。
