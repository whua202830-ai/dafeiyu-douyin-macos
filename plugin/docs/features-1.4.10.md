# 1.4.10 本地更新

插件和独立软件共用手编人格。私信按人格中的角色称呼、性格和互动习惯接话，日常不再默认自称“自动回复助手”；对方问是否 AI 时仍如实回答。历史里的机械回复不会被当作必须延续的人格设定。

当前会话的已核对显示名和个人／群聊类型会传给回复模型。只用于接话，不代表核实了对方现实身份，也不提供抖音内部标识、头像、其他联系人或 QQ 聊天历史。没有本轮运行证据时，不编造网络卡顿、刚收到或问题已修好等状态。

观看计时改为一次取时，修复 1 毫秒误差造成“每日观看时长账本损坏”的误报。旧格式仅在其余字段完整合法、时间差符合该写入缺陷的窄范围时，缩短内存中的租约；不会清空每日时长或请求记录。其它损坏仍需核对。

1.4.9 的稳定会话身份、公平排队和中文操作错误提示继续保留。当前只更新本地，尚未发布到 npm、GitHub Release 或插件市场。
