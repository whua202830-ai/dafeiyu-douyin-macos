# 1.4.9 本地更新

两版共用此更新，尚未发布到 npm、GitHub Release 或插件市场。

好友身份使用平台会话标识、用户稳定标识或公开个人主页标识核对。昵称和头像用于辨认界面，不作为授权依据。名单中显示“稳定身份已核对”后，仍只处理所选好友和群聊；群聊只响应 @ 或设定昵称。

旧名单只升级同一个会话 ID 和类型。无法核对的旧待发记录留给本人处理，不因改名重新发送。缺少稳定标识、出现登录验证、会话类型冲突时停止操作，并在状态中给出原因。

自动回复和自主分享按顺序使用聊天标签，避免连续检查私信占住窗口导致观看提前结束。软件视频页、插件视频页和聊天页各用自己的标签。遇到同名标签归属冲突时先提示核对。

超时提示包含操作名称。写入超时表示结果尚未确认，应刷新核对；程序不会重复提交。状态轮询失败会撤下旧在线状态，恢复后清除对应连接提示；之前操作的未确认提示单独保留。

允许时段、每日额度、名单、模型密钥及共用记忆沿用原设置。需要手动开始时，可在“视频观看”点击“开始自主观看”；暂停不会清空当天用量。
