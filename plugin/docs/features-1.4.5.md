# 1.4.5 更新说明

本版同步更新 DSH 插件和独立 Windows 软件。软件版使用自己的模型 API Key，保留对话任务；插件在 DSH 原生设置页操作。两个入口共用人格、兴趣、记忆、许可名单和用量，同一时刻只有一个自主观看运行。

## 设置与观看

普通设置修改后自动保存，不再逐项点击保存按钮；无效输入会提示，迟到的轮询或保存回包不会覆盖正在编辑的草稿。密钥仍通过各自专用安全入口保存，不放入普通设置请求或回显原值。

视频观看使用“允许自动观看”开关，在配置的北京时间时段和每日额度内运行。每日观看时长和模型请求上限放在可折叠的高级选项中，可分别选择不限；保留“开始自主观看”和“暂停观看”，无需手动开启新一轮。每日用量刷新可读取实际已计播放时间和已发出的模型请求；Token 在每次模型响应返回后追加，尚未返回的用量不估算成零。

修复重复分享导致观看结束、换片过渡帧与旧模型决策误作用于新作品、计时租约的微小误差。等待按钮稳定和最终输入时持续核对原作品，只发送一次可信输入；遇登录、无文字验证码或私信遮挡即停止相关视频操作，不自动处理验证码。

## 好友和群聊

“好友互动”共用一个总开关，默认允许；必须先读取、核对并选中许可好友或群聊，空名单不会向任何人发送。回复与分享不再设置次数或人数上限，自动续火花入口已移除。旧收据和去重记录保留，开关切换不会重发旧作品。

会话和分享按钮按平台稳定身份核对，昵称与头像供用户核对和界面显示。身份或类型不明的会话不可选；分享最终点击瞬间如果目标变化会被拦住。群聊只在被 @ 或叫到配置的响应昵称时回复，普通群消息不启动回复模型请求。

回复按共用的手编人格表达，不添加固定“自动回复”前缀。表情优先读取网页名称；普通图片和无名称表情只采集对应消息区域。已开启本地 Whisper 时可转写单条语音；未识别到对白不会声称听懂，也不把私信内容写入全局视频兴趣。

适配当前抖音网页的作品分享面板，分享当前实际观察作品的官方卡片。新失败保存阶段、错误码和去敏说明，两版可以查看；真正不确定的发送仍暂停并等待人工核对，不自动重试。

## 状态与其他功能

状态栏按真实心跳、会话检查与工作阶段显示等待、看视频、回复中或分享中。正常分享不会被旧预留记录误报为需要处理；缺少回复工作进程或心跳失效时也不会冒充在线。

保留一键自检、按报告执行受限修复、共享用量看板、主题观看、静默观看和 Markdown 日报。公开评论仍须独立开启，沿用单独额度与同作品去重；评论草稿清空不视为发布成功。

## 更新与验证范围

Desktop 在“应用 → 桌面插件”的 npm 包入口填写 `dsh-douyin-browser-local@1.4.5`，更新后完全退出并重开 DSH。Web profile 使用 `dsh plugin --profile web add dsh-douyin-browser-local@1.4.5`。不要用普通 CLI 修改 Desktop profile。

独立软件使用软件内“检查更新”，或从 [GitHub Release](https://github.com/LockyBee/dsh-douyin-agent/releases/tag/v1.4.5) 下载对应 EXE 和 SHA256 文件，正常退出旧版后启动新版。保留原配置、人格、记忆和专用抖音登录资料，不包含本机 QQ 合并启动器。

本地候选完成真实作品卡片分享回执和约 200 秒持续观看验证；两版共享运行与用量已核对。真实群聊、长期无人值守和本轮新收到私信的完整链路尚未额外验收，后台会话打开曾有一次超时后恢复，尚未彻底定位。并发测试中出现过临时人格文件替换 EPERM，单独复跑通过；不能据此保证所有 Windows 环境均无文件占用问题。完整范围见[本地验证记录](verification/local-1.4.5-beta.2-20261025.md)，正式包与公开状态另见[发布记录](publication.md)。
